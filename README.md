# IoTcraft Website

A modern website for IoTcraft built with Astro, Tailwind CSS, and TypeScript. Licensed under the MIT License.

You may also specify url parameters to get quick access to already set up pages of the website. Here's an example: https://iotcraft.teatech.cz/gesture/?url=test&topic=test&firstGesture=Open_Palm&firstGesture=Open_Palm&secondGesture=Victory&secondGesture=Pointing_Up&message=%20&message=%C2%B2
